# Собери мир. Научи ИИ

Интерактивный конструктор для школьного фестиваля наук. Карта спасательного робота, обучение классификатора местности на собственных примерах и испытания в меняющихся условиях. Весь код работает в браузере без ключей, регистрации, внешних библиотек и серверной части.

## Запуск

Откройте `index.html` в браузере. Для школьников можно опубликовать тот же файл на GitHub Pages.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Запустите **Actions → Publish festival app → Run workflow**. После успешного развёртывания адрес появится в разделе Pages и в окружении github-pages.

Ожидаемый адрес для этого репозитория: https://alu-vidor.github.io/science-festival-2026-1/ (работает только после публикации).

## Сценарий занятия

1. Запустите исходную карту с коротким маршрутом: робот попадёт на опасную местность.
2. Выберите «Изучить», нажимайте на клетки и отмечайте безопасные и опасные участки. Возьмите несколько примеров каждого класса из разных типов местности.
3. Нажмите «Обучить ИИ» и проверьте прогнозы. Запустите робота с учётом прогноза ИИ.
4. Измените карту, запас энергии или включите дождь. Дополните обучающие примеры и повторите испытание.
5. На интерактивной панели используйте «Режим панели». Каждый компьютер работает независимо; синхронизации, общего рейтинга и удалённого управления нет.

## Математическая модель

Полигон — граф 12 × 12 с четырьмя направлениями движения. Стены непроходимы. Признаки местности: влажность, уклон и неровность (0–100). Робот застревает при влажности ≥ 70, уклоне ≥ 70 или сумме влажности и неровности ≥ 110. Дождь прибавляет 25 к влажности с ограничением 100. Эти условные правила описывают учебную среду, а не реальную робототехнику.

Обучение — k ближайших соседей, k = min(3, число примеров), евклидово расстояние по признакам. Метки назначает участник. Прогноз опасности — доля опасных среди ближайших примеров. Обучение фиксирует снимок данных; после новых отметок нужно нажать «Обучить ИИ» повторно. Проверка на тех же примерах не считается оценкой качества на новых данных.

Маршрут — алгоритм Дейкстры до ближайшей по стоимости посылки, затем новый поиск. Базовая стоимость ребра 1; в режиме ИИ добавляется 30 × прогноз опасности. Расход энергии считается отдельно (дорога 1, грязь 3, холм 4, вода 5). Зарядка восполняет исходный запас один раз за испытание. Это эвристическая стратегия с учётом риска, а не оптимизация полного тура или запаса батареи.

## Проверка

`node tests/model.cjs` проверяет построение полигона, опасность исходного короткого маршрута, безопасную доставку при корректно размеченной обучающей выборке, стоимость такого маршрута, исправление повторных меток и изменение влажности.

Данные находятся только в памяти вкладки и сбрасываются при перезагрузке. Сторонние запросы и сбор персональных данных отсутствуют.

## Вторая вкладка «Город и эпидемия»

Карта города: шесть жилых кварталов по 10 жителей, школа, мастерская, магазин, парк и автобусный узел. Нажатие на общественное место меняет его работу, на квартал — место первого случая. Движение показывает расписание модели: дорога, дневные занятия, прогулка, возвращение домой. Линии улиц служат ориентиром; масштаб и время движения условны.

На каждом этапе контакты возникают только между жителями одного места. Шанс контакта пары за этап: 0,8 дома, 0,22 в автобусном узле, 0,25 в дневных местах, 0,12 в парке. Шанс передачи равен шансу контакта, умноженному на параметр передачи. Новые случаи становятся заразными со следующего этапа. Длительность отсчитывается ночными обновлениями. Переболевшие не заражаются повторно. Это учебные допущения, а не параметры реального вируса.

Закрытое место заменяется пребыванием дома. Без автобуса южные кварталы остаются дома, северные могут посещать дневные места пешком. Показатель активности — доля состоявшихся дневных дел и прогулок относительно открытого города за те же этапы. Общий транспорт не входит в этот показатель посещений. Снимок каждого этапа содержит расположение жителей и новые случаи с указанием места.

Номер опыта фиксирует случайность. Пары получают одни и те же случайные числа независимо от открытых мест. Итоги можно сравнивать в таблице, которая хранится в памяти вкладки. В этом интерактиве работает симуляция без ИИ. Обучение ИИ находится на вкладке робота.

Проверки: `node tests/epidemic.cjs` и `node tests/model.cjs`. Для публикации нужны index.html, epidemic.html и epidemic.js. Workflow копирует их автоматически.
