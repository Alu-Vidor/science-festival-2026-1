# Собери мир. Научи ИИ

Интерактивный конструктор для школьного фестиваля наук. Карта спасательного робота, обучение классификатора местности на собственных примерах и испытания в меняющихся условиях. Весь код работает в браузере без ключей, регистрации, внешних библиотек и серверной части.

## Запуск

Откройте `index.html` в браузере. Для школьников можно опубликовать тот же файл на GitHub Pages.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Запустите **Actions → Publish festival app → Run workflow**. После успешного развёртывания адрес появится в разделе Pages и в окружении github-pages.

Ожидаемый адрес для этого репозитория: https://alu-vidor.github.io/science-festival-2026-1/ (работает только после публикации).

## Сценарий занятия

1. Запустите исходную карту с коротким маршрутом: робот попадёт на опасную местность.
2. Выберите «Изучить», нажимайте на клетки и отмечайте безопасные и опасные участки. Возьмите несколько примеров каждого класса из разных типов местности.
3. Нажмите «Обучить ИИ» и проверьте прогнозы. Запустите робота с учётом прогноза ИИ.
4. Измените карту, запас энергии или включите дождь. Дополните обучающие примеры и повторите испытание.
5. На интерактивной панели используйте «Режим панели». Каждый компьютер работает независимо; синхронизации, общего рейтинга и удалённого управления нет.

## Математическая модель

Полигон — граф 12 × 12 с четырьмя направлениями движения. Стены непроходимы. Признаки местности: влажность, уклон и неровность (0–100). Робот застревает при влажности ≥ 70, уклоне ≥ 70 или сумме влажности и неровности ≥ 110. Дождь прибавляет 25 к влажности с ограничением 100. Эти условные правила описывают учебную среду, а не реальную робототехнику.

Обучение — k ближайших соседей, k = min(3, число примеров), евклидово расстояние по признакам. Метки назначает участник. Прогноз опасности — доля опасных среди ближайших примеров. Обучение фиксирует снимок данных; после новых отметок нужно нажать «Обучить ИИ» повторно. Проверка на тех же примерах не считается оценкой качества на новых данных.

Маршрут — алгоритм Дейкстры до ближайшей по стоимости посылки, затем новый поиск. Базовая стоимость ребра 1; в режиме ИИ добавляется 30 × прогноз опасности. Расход энергии считается отдельно (дорога 1, грязь 3, холм 4, вода 5). Зарядка восполняет исходный запас один раз за испытание. Это эвристическая стратегия с учётом риска, а не оптимизация полного тура или запаса батареи.

## Проверка

`node tests/model.cjs` проверяет построение полигона, опасность исходного короткого маршрута, безопасную доставку при корректно размеченной обучающей выборке, стоимость такого маршрута, исправление повторных меток и изменение влажности.

Данные находятся только в памяти вкладки и сбрасываются при перезагрузке. Сторонние запросы и сбор персональных данных отсутствуют.

## Город с настраиваемым населением

В каждом из шести кварталов задаются взрослые и дети отдельно, от 0 до 20 каждой группы. Город может содержать от 0 до 240 жителей. По умолчанию 72 жителя. Пустой город можно настроить, но запуск требует хотя бы одного жителя. Первый случай выбирается из заданного непустого квартала.

Пять этапов дня: 08:00 дорога, 10:00 учёба и работа, 16:00 покупки, 18:00 спорт и отдых, 22:00 дом. Дети посещают школу, взрослые — работу и магазин. Спортцентр и парк доступны обеим группам. Доля спортцентра применяется первой, доля парка — к оставшимся. Если автобус выключен или житель не выбрал его, он посещает дневное место пешком. Вероятность посещения определяется отдельно для каждого жителя, дня и места по фиксированному номеру опыта.

Модель считает передачу только между жителями одного места. Шанс контакта пары за этап: дома 0,35; парк 0,06; автобус 0,18; спорт 0,23; школа, работа, магазин 0,15. Общая вероятность передачи для пары — произведение шанса контакта и параметра передачи. Никакого ограничения числа контактов при росте населения нет, поэтому скопления повышают риск в этой учебной модели. Взрослые и дети отличаются маршрутами и размером фигурок, а не биологической восприимчивостью.

Заразный период равен заданному числу дней × 5 этапов. Новые случаи передают вирус со следующего этапа. Переболевшие не заражаются повторно. Остановка: исчезновение заразных либо 60 дней, с разными сообщениями для этих исходов.

Показатели: заразны сейчас, максимум за показанную часть опыта, первое время достижения максимума, суммарное число и доля случаев, число жителей вне дома на текущем этапе. Условный процент «состоявшихся посещений» удалён. Таблица сохраняет параметры, пик и его время, число и долю случаев. «До итога» позволяет завершить показ без ожидания анимации.

На карте в каждом месте показывается до 60 фигурок. Остальные находятся внутри здания: их число подписано, все жители участвуют в расчёте. Фигурки ограничены площадкой перед зданием. Три скорости движения, плавный разгон и торможение, кнопка увеличения карты, прокрутка в пределах рабочей области. Расположение на карте и скорость условны.

Проверки: `node tests/epidemic.cjs` и `node tests/model.cjs`. Для публикации нужны index.html, epidemic.html, epidemic.js. Workflow копирует их автоматически. Эта модель вымышленного вируса не является медицинским прогнозом и не использует ИИ. Обучение ИИ находится на вкладке робота.


Город расширен до 15 мест: добавлены детский сад, больница и торговый центр с переключателями и посещаемостью. Каждый третий ребёнок в квартале — дошкольник. На этапе 16:00 сначала выбирается визит в больницу, затем ТЦ для остальных, затем магазин для взрослых. Больница — место краткого приёма, без модели лечения. Карта 1000×1700, пять рядов участков, озеленённые улицы.


Обновление интерфейса: изометрическая карта города, объёмные здания и набережная, проекция маршрутов жителей. Полигон робота: четвёртый признак — прочность грунта (≤30% опасно), песок (2 энергии), прямоугольное и поштучное выделение, групповое изменение материалов/прочности и разметка примеров. Кнопка «Применить к выделению» использует выбранный инструмент. Плавный отдельный слой робота, CSS-эффекты воды, дождя и сканирования с поддержкой reduced-motion. Внешних графических библиотек нет.
