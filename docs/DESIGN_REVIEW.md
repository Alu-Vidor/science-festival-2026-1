# Дизайнерская оценка: школьники 5–11 классов

06.10.2026. Экспертная оценка интерфейса и автоматические проверки; наблюдение с реальными школьниками пока не проводилось.

Интерфейс подходит по направлению для фестивальной игры: понятный цикл действий, крупная карта, короткие пояснения рядом с решениями, возможность попробовать и объяснить результат. Иллюстрированная графика сохранена. Затемнение направляет внимание на один элемент, светлый акцент обозначает основное действие.

| Критерий | Изменение | Граница вывода |
|---|---|---|
| Читаемость | Пояснения 16–18 px, крупные заголовки, светлый контрастный текст | Реальная читаемость зависит от экрана |
| Нажатия | Основные действия от 48 px, отдельное увеличение клеток, клавиатурный фокус | Фигурки SVG требуют точности; есть список жителей |
| Первые минуты | Обучение с подсветкой, назад, пропуск, повтор | Проверяется блокировка фона, Escape и положение карточки |
| Нагрузка | Редактор робота свёрнут, решения сгруппированы, подробности раскрываются отдельно | Стало понятнее, какое действие первое |
| Причины результата | Семьи, запас еды, энергия, очереди, поездки и расходы | Автотесты проверяют связи, сохранение ресурсов и бюджет |
| Возраст | Простой первый цикл; исследование через детали и сравнение | Нужны отдельные наблюдения с 5–6 и 10–11 классами |
| Доступность | Клавиатура, aria-описания, недоступный фон, уменьшение движения | Автотесты не заменяют аудит с экранным диктором |

На телефоне карта остаётся плотной: предусмотрены приближение, перетаскивание и выбор человека из списка. Для одновременного обзора карты и решений удобнее ноутбук или панель. Режим мэра требует чтения: на коротком подходе можно пройти обучение и 2–3 дня, а полный опыт оставить для более длинного занятия. Это проектная рекомендация, время школьников не измерялось.

## Проверки выпуска

- Восемь групп модели и контроллеров проходят локально (`node tests/run.cjs`).
- В HTML нет повторяющихся id и несогласованных закрытий тегов.
- Браузерный сценарий включён в PR workflow: его фактический результат и снимки должны быть проверены перед завершением PR.
- Подготовка GitHub Pages включает новые CSS/JS обучения и переключения режимов.
