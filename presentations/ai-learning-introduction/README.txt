МАТЕРИАЛЫ ПЛОЩАДКИ «поИИграем?»

ai-learning-introduction.pptx — шесть редактируемых светлых слайдов 16:9.
ai-learning-introduction.pdf — те же слайды для показа без PowerPoint.
facilitator-guide.docx — отдельный сценарий ведущего: реплики, действия,
вопросы детям, переходы между интерактивами и памятка по управлению.
facilitator-guide.pdf — сценарий для печати.
facilitator-guide.txt — сценарий в обычном тексте.
presenter-notes.txt — пояснения к шести слайдам; также встроены в PPTX.

Для показа в браузере распакуйте slides-and-browser-player.zip целиком
в одну папку и откройте index.html. Интернет для показа не нужен.
Переключение: стрелки ← →, Home / End. Полный экран: F или кнопка ⛶.
Кнопка «Скачать материалы» открывает ссылки на презентацию и сценарий.

Содержание слайдов: ИИ и машинное обучение; данные; обучение с учителем;
обучение без учителя; обучение с подкреплением; проверка в новых условиях.
Примеры связаны с роботом и городской агентной симуляцией площадки.
Порядок занятия и действия ведущего вынесены в отдельный сценарий.

Источники для редактирования: slide-content.json, facilitator-script.json,
build_materials.py, assets/robot-and-city.png.
Сборка: python build_materials.py
Нужны Python с python-pptx, python-docx, reportlab, PyMuPDF, LibreOffice
и шрифты Liberation Sans в /usr/share/fonts/truetype/liberation.
